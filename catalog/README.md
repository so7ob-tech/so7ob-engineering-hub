## Required verification before ranking

Confirm repository identity and project type; inspect the official license; review recent commits and releases; read project docs and deployment instructions; inspect test and security practices; verify technology claims and Arabic/RTL support rather than inferring them; cite the specific sources used and the date checked. A stars count without a date is not an evidence record.
