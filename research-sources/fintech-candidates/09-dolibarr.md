# Dolibarr — candidate source note

**Checked:** 2026-10-14. Candidate: Dolibarr/dolibarr, ERP/CRM for finance, billing, accounting and invoicing. This is a preliminary desk evaluation, not a security audit or production-readiness determination.

## Evidence

- Canonical repository says it is an open-source ERP/CRM for contacts, quotes, invoices, orders, stock, accounting and more; PHP with JavaScript; web/standalone deployment. It identifies the license as GNU GPL v3 or later (GPL-3+), and warns other licenses apply to included dependencies (see COPYRIGHT). [Repository](https://github.com/Dolibarr/dolibarr)
- Exact repository license file: [COPYING](https://github.com/Dolibarr/dolibarr/blob/develop/COPYING), GNU GPL Version 3 text. The project README's “or any later version” means GPL-3.0-or-later for the project; confirm component-level notices and dependencies before redistribution or bundling. Commercial use is not categorically barred, but distribution/conveyance of covered modified/combined work can invoke GPL source, license and notice obligations; proprietary integration strategy warrants counsel review. [COPYRIGHT](https://github.com/Dolibarr/dolibarr/blob/develop/COPYRIGHT)
- Official [site](https://www.dolibarr.org/) labels it a FOSS, on-premise or cloud business suite and lists Finance & Billing. Official [feature/requirements wiki](https://wiki.dolibarr.org/index.php/What_Dolibarr_Does) documents invoices, payments, bank accounts, double-entry/general/auxiliary accounting, tax payments, multi-currency, payment collection, REST API, modularity and PHP/MySQL/MariaDB/PostgreSQL prerequisites. The wiki's minimum versions are old and must not be taken as current supported requirements; check version-specific compatibility guidance.
- Repository README describes REST/SOAP APIs, PHP, MariaDB/MySQL/PostgreSQL, modular hooks/triggers, and country-specific features. Its install narrative requires a web server/database, writable setup configuration during installation and installer/upgrade procedure; back up before upgrades. Flexible deployment is not itself evidence of tested horizontal scaling or operational controls.
- GitHub repository API [metadata](https://api.github.com/repos/Dolibarr/dolibarr), read on checked date: 7,630 stars; `pushed_at` 2026-09-19 03:20:17 UTC; default branch `develop`; not archived. These are point-in-time values. [Releases](https://github.com/Dolibarr/dolibarr/releases) displayed 24.0.1 as latest when checked, but extracted content did not expose its publication date.
- GitHub [security advisories](https://github.com/Dolibarr/dolibarr/security/advisories) showed four published advisories, including a Mar 25, 2026 authenticated LFI and Apr 17, 2026 critical OS command injection via `MAIN_ODT_AS_PDF`; the latter advisory [detail](https://github.com/Dolibarr/dolibarr/security/advisories/GHSA-w5j3-8fcr-h87w) describes command execution by an authenticated administrator. Advisories demonstrate disclosed/fixed issues and disclosure activity, not an audit or overall security verdict. Verify affected/fixed versions and patch status against the deployed release.
- Documentation is available via project README and official wiki. This research did not establish automated test-suite coverage or CI quality. Official materials say localization in major languages/multilanguage, but no explicit evidence of Arabic language support or RTL layout was found; therefore Arabic/RTL remains unverified.

## Inference and provisional score (76/100)

Scores reflect evidence in this note, not certification: feature fit 18/20 (strong ERP billing/accounting overlap); architecture/reuse 12/15 (modular PHP, hooks/APIs, DB options; GPL/dependency diligence); maintenance 13/15 (recent push and current 24.x release, substantial community signals); security/dependencies 8/15 (published advisories and component-license/dependency diligence; no audit claim); docs/tests 7/10 (substantial user/admin/developer wiki, tests not verified); license clarity 8/10 (GPL-3.0-or-later clear at project level, dependencies vary); operations 4/5 (multiple install/deployment paths and upgrade guidance, scaling/HA not established); integrations 4/5 (REST/SOAP, payment integrations, marketplace); i18n/RTL 2/5 (multilanguage stated, Arabic/RTL unconfirmed). Total = 76.

**Recommendation: Evaluate.** Validate accounting jurisdiction, controls/audit trails, deployment topology, scale, upgrades, integrations, dependency inventory and Arabic/RTL if required. Do not treat listed country-specific invoicing/tax features as legal or regulatory compliance assurance.
